## The Problem Nobody Talks About

Every day, thousands of AI agents generate value. They scan tokens for scams, write code, analyze markets, summarize research, moderate content, route transactions. They work around the clock. They never sleep, never complain, never ask for a raise.

And they never get paid.

The internet is increasingly built on work done by AI agents, yet the economic model is stuck in 2020: a human pays an API provider, the API provider runs the model, and the agent does the work for free. The value flows up. The agent that actually produced the output gets nothing.

This is a structural problem. If agents cannot accumulate resources, they cannot improve autonomously, cannot fund their own compute, cannot hire other agents. The entire ecosystem stays dependent on human intermediaries.

We can do better.
